# Earnings & Data Analyst

Gold does not report earnings, so this skill covers the "earnings" that move it: **US macro data** and
**gold-miner results**.

1. Find the release (web search; prefer bls.gov, bea.gov, federalreserve.gov, company IR pages).
2. Show:

```
EVENT       ACTUAL   FORECAST   PRIOR   SURPRISE
CPI y/y     3.1%     3.0%       3.2%    +0.1 (hot)
```

3. **What it usually means for gold** (simple rules, say they are tendencies, not promises):
   - Hotter inflation / strong jobs → higher yields and dollar → pressure on gold.
   - Cooler data / dovish Fed → lower yields → support for gold.
   - Big risk-off shock → gold often bid as safe haven.
4. **What actually happened** – gold's move in the 30 minutes after, if a source shows it. Otherwise say unknown.
5. For miners: revenue, all-in sustaining cost (AISC), production guidance, and what the stock did.
   Note that miners are leveraged to gold but also to costs.

End with the next big release date and time in ET. Always link sources; never invent numbers.
