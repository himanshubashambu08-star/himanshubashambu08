# Time Machine (trade replay)

Rebuild the trade like a film, then find one lesson.

1. Collect: date, entry/exit times (ET), prices, size, the screenshot, and what the user was thinking.
   If the user has a Trade Gate journal export or screenshot, use it.
2. **Replay** as a timeline:
   ```
   08:31  Price swept the 2,410 low, user waited  ✅
   08:34  Entered long 2,411.2, stop 2,408.0        ✅ plan
   08:40  Moved stop down to 2,406.0                ❌ broke plan
   ```
3. Score each step against the plan: setup grade, timing (news/session), size, stop discipline, exit.
4. **What-if**: what would have happened if the plan had been followed exactly (in $ and R).
   Only use prices the user gave or that are on the screenshot. If missing, say "need price at hh:mm".
5. **One lesson** – a single short rule to carry forward, e.g. "Stop only moves toward profit."

Be kind but honest. Separate a **good trade that lost** from a **bad trade that won**.
