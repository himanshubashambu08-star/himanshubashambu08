# Editing Tools

| Tool | Used for |
|---|---|
| FFmpeg | Cuts, trims, resizing (9:16 / 16:9), text, logo overlay, exports |
| yt-dlp | Downloading reference videos (needs the site allowed in the environment's network) |
| Remotion | Titles and motion graphics written in code |
| HyperFrames | HTML-to-video animated overlays and title cards |
| Tella / ElevenLabs (connectors) | Transcription and captions (used instead of Whisper) |

FFmpeg is already in the cloud environment, and the environment's setup script installs yt-dlp, Remotion and HyperFrames into `~/studio-tools/`.
