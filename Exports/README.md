# Exports

Rendered output from editing — drafts and finals ready for review.

**What goes here**
- Exported videos, named to match their `Raw/` folder, e.g. `2026-11-11_product-review_v1.mp4`
- Increase the version number (`_v2`, `_v3`) for each revision
- Platform-specific cuts can be suffixed, e.g. `_9x16.mp4` for Reels/Shorts, `_16x9.mp4` for YouTube

Once a video is approved, copy the final version into `Approved Videos/`.
