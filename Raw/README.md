# Raw

Unedited footage waiting to be edited — **one folder per video**.

**How to use**
1. Create a new subfolder for each video, e.g. `Raw/2026-11-11_product-review/`
2. Put all the raw clips, B-roll, voiceover and audio for that video inside it
3. Optionally add a `brief.md` in the folder describing the goal, platform, target length, and any special instructions

Example:
```
Raw/
└── 2026-11-11_product-review/
    ├── brief.md
    ├── a-roll.mp4
    ├── b-roll-01.mp4
    └── voiceover.wav
```
