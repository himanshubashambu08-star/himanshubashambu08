# Video 01: Storylines

Style B (motion-graphics "interactive" reel), English, built only with free tools.
Format: 9:16, 1080×1920, 35–50 s. Voiceover from the free local Kokoro voice, word-by-word captions,
locally made ambient sound. Nothing paid.

## 1. The Vault (recommended: simplest hook, and the comment CTA is the easiest to act on)
- **Device / form:** a number lands + a "YOU" moment / one continuous take down a wall of steel boxes
- **What you see and feel:** a bank vault with 10,000 safety-deposit boxes, all empty, and a counter reading "BOXES CLAIMED 0 / 10,000". Every follower gets a box with their name on it, but box 0777 was already locked when the vault was built, and it rattles every night.
- **First 2 s:** a giant steel door swings open on "10,000 BOXES. ALL EMPTY." with the counter already on screen
- **Beats:** hook (vault opens) → rule (follow = a box with your name) → counter climbs 0 → 1,000 → 10,000 → camera flies along the wall → "YOU" box lights up with a name tag → twist: box 0777 is already locked and shaking → CTA "Comment a box number to claim it"
- **Look:** near-black ground, brushed-steel grid, one emerald-green glow accent, heavy white condensed type
- **Sound:** low vault hum, metal clunks on each counter jump, one heartbeat thud on the twist

## 2. The Last Library
- **Device / form:** a question with the input / an endless zoom
- **What you see and feel:** a library of 1,000,000 books, each with a follower's name on the spine. The camera dives into a shelf, then a spine, then a page, and finds book #000,001 already written, about you.
- **First 2 s:** golden letters on a dark spine spell "YOUR NAME HERE", and the camera starts pulling back
- **Beats:** hook (your-name spine) → pull back to an endless library → counter "BOOKS WRITTEN 0 / 1,000,000" → zoom into book #000,001 → its first line describes the viewer watching this reel → CTA "Comment a shelf number"
- **Look:** warm dark wood, gold foil serif type, candle-light amber accent
- **Sound:** soft page turns, a low choir pad, one book-slam on the reveal

## 3. Don't Press It (the bold one)
- **Device / form:** type carries the argument / one frame that rebuilds
- **What you see and feel:** one red button in an empty black frame. The narrator begs you not to press it, while a counter of everyone who already "pressed" (followed) keeps climbing, and each milestone rebuilds the frame into something stranger.
- **First 2 s:** a single red button and huge type: "DON'T."
- **Beats:** hook "DON'T." → why (the counter at 9,999) → each milestone changes the frame (cracks, alarms, the room tilts) → the button presses itself → CTA "Comment PRESS if you would"
- **Look:** pure black, one saturated red, giant kinetic sans type
- **Sound:** silence broken by alarm stings, a click, then a big bass drop on the self-press
