# References

Videos made by other creators whose style you like and want your edits to feel like.

**What goes here**
- Downloaded clips or screen recordings of videos you admire
- A `links.md` file with URLs for videos you can't download
- Optional notes on *what* you like about each one (pacing, captions, transitions, colour grade, music, hooks)

**Tip:** Name files descriptively, e.g. `fast-cuts-bold-captions_creatorname.mp4`.
